Every file there is to download, in one place. The web tools need no download: they open from **Tools**.

## Alexandria for Rhino

| Download | What It Is |
|---|---|
| <a href={release.url}>Alexandria {release.version}</a> (zip, {release.size} MB) | Both Rhino packages, the docs and quick guides as PDF, and the project template. See [Download](/start/download/) for the two ways to install. |

Office computers install from the office drive instead and update by themselves: see [Install and Update](/docs/install/).

## Fonts

| Download | What It Is |
|---|---|
| [Alexandria Etch](/downloads/etch-font/alexandria_etch_font.zip) (zip) | The single-line font for etched part labels: the font files, the Rhino script and the specimen. See [Alexandria Etch Font](/wiki/downloads/etch-font/). |
| [AlexandriaEtch.ttf](/downloads/etch-font/AlexandriaEtch.ttf) | Just the font file, to install in Windows. It's on the office drive too, in `alexandria_packages`. |
| [Oswald](https://fonts.google.com/specimen/Oswald) (Google Fonts) | The typeface of every Alexandria drawing. Office computers already have it. |
