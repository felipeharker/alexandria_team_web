## Which One to Use

| Where | Use | How |
|---|---|---|
| A browser | [Etch Text](/etch-text/) | Type the label, download an SVG or DXF at real size. Nothing to install. |
| Rhino | `etch_text.py` | Run it, give the text, the height and a point. It draws the label as open curves on the current layer. |
| Inkscape, laser software | `alexandria_etch.svg` | Load it as an SVG font (Hershey Text in Inkscape). |
| CorelDRAW, Word, anything else | `AlexandriaEtch.ttf` | Install it and type. For previews and editable text only: see below. |

## Good to Know

- **Never fill it.** The letters are lines, not shapes: a hairline outline and no fill.
- **The TrueType font isn't for cutting.** A TrueType font can't hold an open line, so it traces each stroke out and back, and a machine would pass twice. Cut from Etch Text's files or the Rhino script's curves.
- **Rhino's own text won't single-line it.** Rhino only treats the fonts on its built-in list as single-line, so the script draws the letters itself.
- **The height is the capitals'.** A 1/2 in label is 1/2 in from baseline to top.
- **Told apart.** The zero is slashed and the one has a flag. Lower case draws as capitals.
