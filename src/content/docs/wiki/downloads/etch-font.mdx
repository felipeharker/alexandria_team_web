## Which One to Use

| Where | Use | How |
|---|---|---|
| A browser | [Etch Text](/etch-text/) | Type the label and download an SVG or DXF. |
| Rhino | `etch_text.py` | Run it and give the text, the height and a point. |
| Inkscape, laser software | `alexandria_etch.svg` | Load it as an SVG font (Hershey Text in Inkscape). |
| CorelDRAW, Word, anything else | `AlexandriaEtch.ttf` | Install it and type. Not for cutting. |
