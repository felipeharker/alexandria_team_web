<About>Alexandria is the office's design lab: a growing set of tools for taking a sign from an empty model to a finished design package. The Rhino toolbar does the modeling and renders, and the web tools handle the rest, from site plans and braille to paint matches and pricing. The office's standards are built in, so every package comes out looking like ours without anyone setting it up by hand. If something's missing or could work better, tell the Alexandria team.</About>
