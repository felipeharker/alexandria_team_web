## The Project

| Project | Alexandria Design Lab |
|---|---|
| Client | Alexandria |
| Location | 1955 Meridian Avenue, Anytown, ST 00000 (made up) |
| Scope | One set of halo-lit reverse channel letters, *Alexandria Design Lab*, centred on the template wall |
| Sign | 4'-0" capitals in Gotham Medium, 64'-5 13/16" long, baseline 25'-6" above grade, 4" returns on 2-1/2" standoffs (DTL-05) |
| Context | Populate Model's wall (its face the y = 0 plane), ground and 5'-6" scale figure, and nothing else |

## How It Was Made

In the order the [Rhino Tools Quick Guide](/rhino/#order) gives:

1. **Create Project** copied the project template and saved the model.
2. **Populate Model** added the layers, styles, wall, ground and scale figure. The letters were modeled on the wall.
3. **Set Light** made the halo, and **Set Material** gave the letters their material.
4. The sign elevation was drawn flat, below the wall.
5. The **Layout Manager** made the pages and placed the elevation and the letter section, DTL-05.
6. **Render Day and Save** and **Render Night and Save** made the two renders, and the Layout Manager exported the PDF.

The Layout Manager is off the team's toolbar until it's ready, so only Felipe's Rhino has it for now.
