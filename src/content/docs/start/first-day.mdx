Alexandria is the office's set of tools for sign design in Rhino 8: a toolbar that takes a sign from an empty model to a finished design package, Grasshopper components for patterns, and office tools like the Material Estimator. This page gets you set up and points you at the right guides.

<Steps>

1. **Install the two packages.** Follow [Install and update](/docs/install/): add the office's Alexandria folder to Rhino's Package Manager, install both packages, and restart Rhino. Once per computer, about ten minutes. Away from the office drive, use the [zip](/start/download/) instead.

2. **Run Alexandria Setup.** Type `AlexandriaSetup` in Rhino and press Enter. The **Alexandria Tools** tab appears after **Standard**, and the `DM-…` display modes join every viewport's display menu.

3. **Read the Rhino tools guide.** [Alexandria Tools](/guides/rhino-tools/) shows every button in the order you'll use it, from Create Project to the finished PDF.

4. **Try it on a practice project.** In a new model, click **Create Project** and pick a scratch folder of your own. Then **Populate Model**, model a simple sign at the origin facing −Y, and try **Set Material** and **Apply Day Settings**. Nothing you do there touches a real project.

5. **Open Grasshopper when a job calls for a pattern.** [Alexandria Phoenix](/guides/grasshopper-components/) shows the basic chain: cells, a value for each, then scale, cull or fold them.

6. **Bookmark the office tools.** The [Material Estimator](/tools/) prices a project's materials.

</Steps>

## Good to know

- **Updates install themselves** when Rhino starts, if you ticked automatic updates while installing. After one arrives, restart Rhino and click **Alexandria Setup** once more. [What's new](/start/whats-new/) lists every release.
- **The standards are built in.** Layers, annotation styles and page layouts come from the tools, so you rarely need to set them by hand. [Standards](/docs/standards/) explains them when you want to know why.
- **Stuck?** [Troubleshooting](/start/troubleshooting/) covers the usual problems. For anything else, ask the Alexandria team for now; a form for questions and suggestions is on its way.
