Alexandria is the office's set of tools, in four categories. The **Rhino/Grasshopper** tools are installed once and run inside Rhino 8. The **Design**, **Parametric** and **Fabrication** tools are on the web at alexdesignlab.org: they open in any browser, on any computer or phone, with nothing to install, and every visit gets the newest version. Bookmark the ones you'll use.

## Rhino/Grasshopper Tools

For modeling the sign and producing its design package. Set them up once:

<div class="ax-tool-list not-content">
<ToolRow title="Alexandria Tools" art="alexandria-tools" href="/rhino/" guide="/rhino/">A toolbar that takes a sign from an empty model to a finished design package: the project, materials and lights, day and night renders, details and the layout.</ToolRow>
<ToolRow title="Alexandria Phoenix" art="alexandria-phoenix" href="/grasshopper/" guide="/grasshopper/">Grasshopper components for patterns in a region: cells, a value for each, then scale, cull or fold them.</ToolRow>
</div>

<Steps>

1. **Install the two packages.** Follow [Install and Update](/docs/install/): add the office's Alexandria folder to Rhino's Package Manager, install both packages, and restart Rhino. Once per computer, about ten minutes. Away from the office drive, use the [zip](/start/download/) instead.

2. **Run Alexandria Setup.** Type `AlexandriaSetup` in Rhino and press Enter. The **Alexandria Tools** tab appears after **Standard**, and the `DM-…` display modes join every viewport's display menu.

3. **Read the Rhino tools guide.** [Alexandria Tools](/rhino/) shows every button in the order you'll use it, from Create Project to the finished PDF.

4. **Try it on a practice project.** In a new model, click **Create Project** and pick a scratch folder of your own. Then **Populate Model**, model a simple sign at the origin facing −Y, and try **Set Material** and **Apply Day Settings**. Nothing you do there touches a real project. The [Sample Project](/sample-project/) shows where it leads: a finished design package made with the tools.

5. **Open Grasshopper when a job calls for a pattern.** [Alexandria Phoenix](/grasshopper/) shows the basic chain: cells, a value for each, then scale, cull or fold them.

</Steps>

## Good to Know

- **Read the quick guide first.** Every tool has one, about two minutes to read, linked above and under **Quick Guides**.
- **Name it, then export it.** In a web tool, name the project at the top, since it names what you export, and **export** your work (a CSV, PNG, SVG or package file) into the project's folder. The web tools save as you go, but only in the browser you used. [Office Tools](/docs/office-tools/) covers how they work underneath.
- **The web tools update themselves:** every visit gets the newest version, with nothing to install.
- **The Rhino tools update themselves too,** when Rhino starts, if you ticked automatic updates while installing. After one arrives, restart Rhino and click **Alexandria Setup** once more. [What's New](/start/whats-new/) describes the latest updates, in Rhino and on the web.
- **The standards are built in.** Layers, annotation styles and page layouts come from the Rhino tools, and the map style from the Site Plan, so you rarely set them by hand.
- **Stuck?** [Troubleshooting](/start/troubleshooting/) covers the usual problems, on the web and in Rhino. For anything else, ask the Alexandria team for now; a form for questions and suggestions is on its way.
