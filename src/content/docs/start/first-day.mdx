The **Rhino/Grasshopper** tools install once in Rhino 8. Everything else opens in a browser, with nothing to install.

## Rhino/Grasshopper Tools

<div class="ax-tool-list not-content">
<ToolRow title="Alexandria Tools" art="alexandria-tools" href="/rhino/" guide="/rhino/">The Rhino toolbar, from an empty model to a finished design package.</ToolRow>
<ToolRow title="Alexandria Phoenix" art="alexandria-phoenix" href="/grasshopper/" guide="/grasshopper/">Grasshopper components for patterns in a region.</ToolRow>
</div>

<Steps>

1. **Install both packages.** Follow [Install and Update](/docs/install/), about ten minutes. No office drive? Use the [zip](/start/download/).

2. **Run Alexandria Setup.** Type `AlexandriaSetup` in Rhino and press Enter.

3. **Try a practice project.** Choose **File › New › Alexandria**, click **Create Project** and pick a scratch folder. The [Rhino guide](/rhino/) has every button in order, and the [Sample Project](/sample-project/) shows a finished package.

</Steps>

## Good to Know

- **Export your work.** A web tool saves only in the browser you used. Name the project, then export into its folder.
- **Updates are automatic.** Web tools on every visit, Rhino tools when Rhino starts. After a Rhino update, restart and click **Alexandria Setup**.
- **Stuck?** See [Troubleshooting](/start/troubleshooting/), or ask the Alexandria team.
