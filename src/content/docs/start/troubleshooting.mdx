## The Web Tools

- **My sheet, list or plan is gone.** The tools save in the browser you used. Another browser, another computer, a private window or clearing the browser's site data starts empty. Import the CSV you exported, or start again; from now on, export into the project's folder.
- **A tool looks out of date or half drawn.** Reload the page to get the newest version.
- **The Color Matcher says the libraries didn't load.** Reload the page; if it keeps happening, check the connection.
- **An import skipped rows or filled in values.** The message after an import says which. Compare the file with the tool's [CSV template](/templates/estimator/): the Estimator needs a Material column, the Color Matcher a Hex column.
- **The Site Plan finds nothing for an address.** Add the city and state, or zoom there yourself and click the map. The search allows one press a second.
- **Part of the Site Plan's map is blank.** Its map comes from a free public service: move the map a little or reload. If it stays blank, try again later.
- **The Site Plan's export fails.** Make the browser window smaller, or set the browser's zoom back to 100%, and export again.
- **The Vectorizer's shapes are lumpy, or small details are missing.** Raise **Precision** for a closer fit, or lower it for smoother curves. Start from the largest, cleanest file the client has: a small or heavily compressed JPG traces poorly.
- **The Vectorizer outlines shapes in an extra color, or misses one.** Untick the extra color so it merges into its neighbour, or raise **Colors** and trace again.
- **The Braille Lettering Designer stays on "Loading the Grade 2 translator".** It loads once, the first time you use Grade 2: check the connection and reload. Grade 1 works without it.
- **The braille has capital signs everywhere.** Type the text as it should read, *Restroom*, not *RESTROOM*: braille capitalizes only the start of a sentence, names and acronyms.
- **The Sign Package Maker's title page isn't in Futura.** Futura Bk BT can't be sent with the tool, so it's read from your computer: under **Export**, press **Use Futura from This Computer** and allow it (Chrome or Edge). Until then the company name is in Jost, a close stand-in.
- **A drawing in the Sign Package Maker can't be dimensioned.** It needs a scale: select it and, under **Page**, type the **Real Width** it shows. An SVG or a PDF has one already; set **Drawn At** if the file wasn't drawn full size.
- **A dimension in the Sign Package Maker reads slightly off.** Click on the drawing's own points: the pink square shows a point it has snapped to. A picture has only its corners and middles to snap to, so place an SVG or a PDF where the number matters.
- **AutoCAD asks to recover a DWG from the Sign Package Maker.** Export the **DXF** instead: it's the office's standard linework file, and holds the same lines.
- **A material isn't in the Estimator's list.** The list comes from the [Material Library](/materials/), which is still being filled in. Type the material in by hand for now.

## Updating

- **A new release hasn't arrived.** Rhino looks for updates only as it starts, so restart it, then restart once more to load the update. Without automatic updates, run `PackageManager`, open **Updates** and click **Update** on each Alexandria package.
- **New buttons are missing after an update.** Click **Alexandria Setup** once. With more than one Rhino open, close the others first: the last Rhino to close decides what the toolbar looks like next time.
- **A definition says "Input parameter chunk is missing".** It was saved before one of its components gained an input. Save it again and the message goes.

To see which version you have, open the **Installed** tab of the Package Manager and compare it with the newest release on [Download](/start/download/).

## Installing from the Zip

- **The packages don't show up in the search.** The sources value has to hold the full path of the folder with the `.yak` files in it, not a folder above it.
- **An update never arrives.** Installs from the zip don't update by themselves. [Download](/start/download/) the new zip and replace the folder's contents with it.
