## The Web Tools

- **My work is gone.** The tools save only in the browser you used. Import the file you exported, and export into the project's folder from now on.
- **A tool looks out of date or half drawn.** Reload the page.
- **An import skipped rows.** The message after it says which. Compare the file with the tool's [CSV template](/templates/estimator/).

### Site Plan

- **Nothing found for an address.** Add the city and state, or zoom there and click the map.
- **Part of the map is blank.** Move the map a little or reload. If it stays blank, try again later.
- **The export fails.** Make the window smaller, or set the browser's zoom to 100%.

### Vectorizer

- **Lumpy shapes or missing detail.** Raise **Precision** for a closer fit, lower it for smoother curves. Start from the largest, cleanest file the client has.
- **An extra color, or a missing one.** Untick the extra, or raise **Colors**.

### Braille Lettering Designer

- **Stuck on "Loading the Grade 2 translator".** Check the connection and reload. Grade 1 works without it.
- **Capital signs everywhere.** Type *Restroom*, not *RESTROOM*.

### Sign Package Maker

- **A dimension reads X'-X" in red.** The drawing has no real size yet. Click a dimension you know and type its **Real Length**, such as 21'-9". The rest fill in.
- **A dimension reads slightly off.** Click on the drawing's own points: a pink square shows the snap. For exact numbers, place an SVG or a PDF, not a picture.
- **Edit Its Parts is greyed out.** The drawing has live text, pictures, gradients or masks. Save it with its text as outlines and place that. Trace a picture in the Vectorizer first.
- **The title page isn't in Futura.** Under **Export**, press **Use Futura from This Computer** (Chrome or Edge).
- **AutoCAD asks to recover a DWG.** Export the **DXF** instead.

### Image Grid

- **The cells barely change size.** The image is low in contrast. In **Standard**, under **Tone**, raise **Black** and lower **White**.
- **An image won't open.** Save it as a PNG or JPG and try again.

### Color Matcher and Material Estimator

- **The Color Matcher's libraries didn't load.** Reload the page.
- **A material isn't in the Estimator's list.** The [Material Library](/materials/) is still being filled in. Type it in by hand.

## Updating

- **A new release hasn't arrived.** Restart Rhino twice. Without automatic updates, run `PackageManager`, open **Updates** and click **Update** on each Alexandria package.
- **New buttons are missing.** Click **Alexandria Setup**. Close any other Rhino windows first.
- **"Input parameter chunk is missing".** Save the definition again.

Your version is on the Package Manager's **Installed** tab. The newest is on [Download](/start/download/).

## Installing from the Zip

- **The packages don't show up in the search.** The sources value needs the full path of the folder that holds the `.yak` files.
- **An update never arrives.** Zip installs don't update themselves. [Download](/start/download/) the new zip and replace the folder's contents.
