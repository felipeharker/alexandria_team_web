## Install

<Tabs>
<TabItem label="From the Office Drive">

The best way: Rhino updates itself. Follow [Install and Update](/docs/install/).

</TabItem>
<TabItem label="From the Zip">

For a computer that can't reach the office drive.

<Steps>

1. Download the zip and unzip it somewhere it can stay, like `Documents\alexandria_packages`.
2. In Rhino, open **Tools › Options › Advanced** and search for `PackageManager.Sources`. Set it to `https://yak.rhino3d.com;` followed by the unzipped folder's full path.
3. Run `PackageManager`, search for `Alexandria`, install both packages and restart Rhino.
4. Type `AlexandriaSetup` and press Enter.

</Steps>

To update, download the new zip, replace the folder's contents and restart Rhino.

</TabItem>
</Tabs>
