## Install

<Tabs>
<TabItem label="From the Office Drive">

**Best** · updates itself with each release · [Install and Update](/docs/install/)

</TabItem>
<TabItem label="From the Zip">

Off the office drive

<Steps>

1. **Unzip** somewhere it can stay · `Documents\alexandria_packages`
2. **Tools › Options › Advanced** · `PackageManager.Sources` · set to `https://yak.rhino3d.com;` + the unzipped folder's full path
3. **`PackageManager`** · search `Alexandria` · install both · restart Rhino
4. **`AlexandriaSetup`** · Enter

</Steps>

To update · new zip · replace the folder · restart Rhino

</TabItem>
</Tabs>
