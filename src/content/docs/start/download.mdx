The zip is an exact copy of the office's shared `alexandria_packages` folder: both packages, the docs as Markdown and PDF, the two quick guides and the project template.

## Two Ways to Install

<Tabs>
<TabItem label="From the Office Drive">

**Use this one if you can.** Rhino installs from the shared folder and updates itself whenever a new release lands there, so you never need the zip. Follow [Install and Update](/docs/install/).

</TabItem>
<TabItem label="From the Zip">

For a computer that can't reach the office drive.

<Steps>

1. Download the zip and unzip it somewhere it can stay, like `Documents\alexandria_packages`.
2. In Rhino, open **Tools › Options › Advanced** and search for `PackageManager.Sources`. Set its value to `https://yak.rhino3d.com;` followed by the full path of the unzipped folder, the one with the `.yak` files in it.
3. Run `PackageManager`, search for `Alexandria`, install both packages, and restart Rhino.
4. Type `AlexandriaSetup` and press Enter.

</Steps>

Installs from the zip don't update by themselves. For a new release, download the new zip, replace the folder's contents with it, and restart Rhino.

</TabItem>
</Tabs>

  - alexandria_tools_quick_guide.html also .pdf
  - alexandria_phoenix_quick_guide.html also .pdf
  - INSTALL.md also .pdf, as [Install and Update](/docs/install/)
  - README.md also .pdf, as [Alexandria Phoenix](/docs/phoenix/)
  - STANDARDS.md also .pdf, as [Standards](/docs/standards/)
  - project_template/ what Create Project copies into a new project's folder

</FileTree>
