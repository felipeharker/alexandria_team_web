## Install

<Tabs>
<TabItem label="From the Office Drive">

**Best** · updates itself with each release

Double-click **Install Alexandria Tools** in `alexandria_packages` · close Rhino when it asks · [Install and Update](/docs/install/)

</TabItem>
<TabItem label="From the Zip">

Off the office drive

<Steps>

1. **Unzip** somewhere it can stay · `Documents\alexandria_packages`
2. **Install Alexandria Tools** · double-click it in that folder · close Rhino when it asks

</Steps>

To update · unzip the new zip over the folder · Rhino installs it as it starts

</TabItem>
</Tabs>
