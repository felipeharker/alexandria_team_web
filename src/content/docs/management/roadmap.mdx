## The Columns

From the [Alexandria · Development Roadmap](https://github.com/users/felipeharker/projects/14) board · one row per issue · edit it there · shows here within two minutes.

| Column | On the Board |
|---|---|
| Item | The issue's title: `Subject: what changes`, such as Site Plan: export to PDF. |
| Category | `Tools`, `R&D`, `Presentations`, `Standards` or `Training`. |
| Subcategory | The narrower part inside it, such as `Rhino`, `Grasshopper`, `Web Tools` or `Hub` under Tools. |
| Status | `Inbox`, `Later`, `Next`, `Doing`, `Waiting` or `Done`. |
| Priority | `Urgent`, `High`, `Normal` or `Low`. |
| Start | The date work starts or started. |
| Target | A real deadline or a commitment, not a guess · a date that has passed on an item that isn't `Done` is marked. |
| Parent | The parent issue · the row folds under it, and the parent gets a dashboard. |
| Issue | The issue, as `#8` · links to it. |
| Notes | **Notes**: what it depends on, what's still open. |
