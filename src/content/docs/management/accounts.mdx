## The Columns

The file is [accounts.csv](/management/accounts.csv), one row per service, under [the CSV standard](/management/#the-csv-standard).

| Column | What Goes in It |
|---|---|
| Service | The service's name, such as GitHub. A row without one is skipped. |
| Description | What it is and what Alexandria uses it for, in a sentence or two. |
| Current account | The account it's on now: `Personal`, `Company`, or a team's name. |
| Migrated (Y/N) | `N` to start, `PARTIAL` while it's under way, `Y` once it has fully moved. The count above the table counts the `Y` rows. |
| Notes | The plan, the date it moved, what still needs linking again. |
