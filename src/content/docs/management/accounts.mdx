## The Columns

From the [Alexandria · Accounts](https://github.com/users/felipeharker/projects/18) board · one item per service · edit it there · shows here within two minutes.

| Column | On the Board |
|---|---|
| Service | The item's title, such as GitHub. |
| Description | What it is and what Alexandria uses it for. |
| Current account | **Account**: `Personal` or `R&D managed team`. |
| Status | `Not migrated`, `Partial` or `Migrated`. The count above the table counts `Migrated`. |
| Notes | The plan, the date it moved, what still needs linking again. |
