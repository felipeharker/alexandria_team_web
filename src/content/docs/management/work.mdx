## The Columns

| Column | On the Board |
|---|---|
| Project | The job: the parent issue's title · its pieces fold under one project row with its progress and **Dashboard ›** · a job with no sub-issues is a row of its own. |
| Work | The sub-issue's title, such as Design package, Permit drawings or Fabrication drawings. |
| Assigned to | **Assigned to**: a first name. |
| Status | `Inbox`, `Later`, `Next`, `Doing`, `Waiting` or `Done`. For `Waiting`, say on whom in Notes. |
| Priority | `Urgent`, `High`, `Normal` or `Low`. |
| Start | The date the work starts. |
| Due | **Due** · a date that has passed on work that isn't `Done` is marked. |
| Issue | The issue, as `#8` · links to it. |
| Notes | **Notes**: what it's waiting on, where the files are. |
