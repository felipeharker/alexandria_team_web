## The Columns

The file is [work.csv](/management/work.csv), one row per piece of work, under [the CSV standard](/management/#the-csv-standard). A project with three people on it has three rows.

| Column | What Goes in It |
|---|---|
| Project | The project or job, spelled the same on each of its rows · from two rows, they fold under one project row with its progress and **Dashboard ›**. A row without one is skipped. |
| Work | What's being done, such as Design package, Permit drawings or Fabrication drawings. |
| Assigned to | Who is doing it: a first name. |
| Status | `Inbox`, `Later`, `Next`, `Doing`, `Waiting` or `Done`. For `Waiting`, say on whom in Notes. |
| Priority | `Urgent`, `High`, `Normal` or `Low`. |
| Start | The date the work starts, as `2026-12-04`. |
| Due | The date it's due, as `2026-12-04`. A date that has passed on work that isn't `Done` is marked. |
| Notes | Anything else: what it's waiting on, where the files are. |
