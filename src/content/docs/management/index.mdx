## Parents and Dashboards

| Part | What It Does |
|---|---|
| Sub-tasks | Rows under a parent · folded under its row · **Unfold all** opens every parent · Find opens the ones it finds. |
| Roadmap | A sub-issue sits under its parent issue · any depth. |
| Project Work | A job's sub-issues fold under the job, from two · the project row rolls them up: status, priority, earliest start, latest due, people. |
| Dashboard | **Dashboard ›** on a parent's row · `/management/dashboard/?roadmap=<item>` · done · late · start · end · status bar · timeline · sub-task list. |
