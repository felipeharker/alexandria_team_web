## The CSV Standard

Each table is one CSV file, and its page shows the file as it is. Every file follows the same rules; each page lists its own columns.

| Rule | What It Means |
|---|---|
| One file per table | A short lowercase name, such as `work.csv`, in `alexandria_office\public\management\`. |
| A header row | The first row names the columns, spelled as the page's **The Columns** gives them. The page finds a column by its name, so the order can change. |
| One row per item | A blank row is skipped. A cell holding a comma or a line break goes in quotes, which Excel does for you. |
| The first column | Names the row: the service, the project or the item. A row needs one. |
| Notes | Always the last column, for anything else. |
| Dates | `2026-12-04`: year, month, day. Leave the cell empty when there's no date yet. If Excel rewrites one as `12/4/2026`, the page still reads it. |
| Status | `Inbox`, `Later`, `Next`, `Doing`, `Waiting` or `Done`, as on the planning board. |
| Priority | `Urgent`, `High`, `Normal` or `Low`, as on the planning board. |
| People | First names. For two people, put `;` between them. |
| Parent | A sub-task's parent: the parent row's first column, spelled as in its row · empty at the top · see [Parents and Dashboards](#parents-and-dashboards). |
| Issue | The planning board's item, as `#8` · links to it. |
| Saving | In Excel, **CSV UTF-8 (Comma delimited)**, so every character survives. |
| No secrets | Never a password, a key, a token or a recovery code, in any cell. They belong in a password manager. |

A column that isn't in a page's list is still shown, as plain text, so a table can gain one whenever it's needed. Add it before Notes, and add it to the page's list.

## Parents and Dashboards

| Part | What It Does |
|---|---|
| Sub-tasks | Rows under a parent · folded under its row · **Unfold all** opens every parent · Find opens the ones it finds. |
| With a Parent column | Roadmap · a row sits under the row it names · any depth. |
| Without one | Project Work · rows sharing a first column fold under it, from two rows · the project row rolls them up: status, priority, earliest start, latest due, people. |
| Dashboard | **Dashboard ›** on a parent's row · `/management/dashboard/?roadmap=<item>` · done · late · start · end · status bar · timeline · sub-task list. |
| The board | Roadmap rows with an Issue follow Project 14 · status, priority, dates, parents · its sub-issues get rows · run `python planning/sync_roadmap.py` in alexandria_management, then push alexandria_office. |

## Changing a Table

1. Open the file in Excel, from `alexandria_office\public\management\`.
2. Change it and save it, keeping the CSV format.
3. Commit and push alexandria_office. The page shows the change within two minutes.
