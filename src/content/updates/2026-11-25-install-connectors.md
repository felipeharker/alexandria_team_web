**To get it:** restart Rhino twice, then click **Alexandria Setup**.

### Install Connectors

A new button beside **Alexandria Setup**. It lists the Claude connectors, Rhino, CorelDRAW and SquareCoil, with where each stands on your PC.

- **Tick the ones to install or update,** or click **Install / Update All**.
- **Afterwards,** quit Claude Desktop from its tray icon and open it again.

### SquareCoil

Claude can now read Aria's design requests: In Progress, Next Job and On Hold. Ask what's due, what's assigned to someone, or what's overdue.

- **Your own login, once.** It's kept in Windows Credential Manager, never in a file.
- **Read-only.** Claude changes nothing in SquareCoil.
- **Skipped it?** Leave the username empty to skip; **Install Connectors** asks again.

[Claude Connectors](/docs/install/#claude-connectors) has the details.
