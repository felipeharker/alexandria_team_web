The Rhino and Grasshopper packages in the office's shared folder are now 2.18. With automatic updates on, Rhino installs them the next time it starts; restart once more to load them, then click **Alexandria Setup** so the new button shows. [Install and Update](/docs/install/#updating) has the details.

### Fabrication Manager

A new button on the Alexandria Tools tab, after the Layout Manager: the shop's 1:1 cut linework, made in Rhino from the design itself.

- **Add Item.** Select the linework (curves, text or hatches), give it a name, a material (aluminum, steel, acrylic, vinyl or other) and a line type (cut, etch, score or fold). It's copied flat at 1:1 into a fab area you place with a click, a row per material, each item labelled.
- **The FAB layers.** Each line type has its own layer, `FAB::CUT`, `ETCH`, `SCORE` and `FOLD`. Populate Model brings them, so every project has them.
- **Update Item.** An item remembers what it was made from, like a drawing does, so after the design changes it copies the linework again.
- **Add Linework** adds lined-up fold or etch lines to an item.
- **Export DXF** writes one DXF per material, `FAB_<project>_<material>_v#.dxf`, in the folder you choose, the project's new `fabrication` folder first: R12 DXF, which every cutting program opens, with closed polylines of lines and arcs, a layer per line type, at 1:1 and at the origin.

See the [Rhino Tools quick guide](/rhino/).

### Layout Manager

- **Blocks.** A new part places blocks from the block library on a page where you click: north arrows, callouts and other symbols at paper size; people, cars, trees and graphic scales at the scale you choose. **Largest That Fits** takes the scale of the page's largest view, so a graphic scale matches the drawing. **Remove from Page** takes them off again.
- **Renders join Images.** The Renders part is gone; Images has a **Category** instead. **Render** gives the page its render and a day or night sky, as before. **Site Plan** and **Other** place an image where you click, such as a Site Plan export.

### Grasshopper

- A [parameters CSV template](/templates/grasshopper/) for Export Parameters and Apply Parameters: the input name, type, value and section columns, with every value type.
