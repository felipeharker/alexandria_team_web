### Render and Save

Apply Day Settings and Apply Night Settings now only set the look. The new Render and Save button renders the active view, and once it's done asks whether to save with the sky and where, at the next `day_#` or `night_#`.

### Layout Manager and Fabrication Manager

Off the Alexandria Tools toolbar for now, while they're finished.
