From Model to Package

  1. Create Projectdesign_models / <project>_model_v1.3dm
  2. Populate ModelSkip it in a model from the Alexandria template.
  3. Model the SignFull size, each part on a DESIGN sublayer.
  4. Materials and LightSet Material on DESIGN, Set Light on the lit faces.
  5. RenderOne view for day and night. design_renders / day_# night_#
  6. Draw and DimensionElevations and plans, flat in the Top view.
  7. Pages and PDFdesign_package / DESIGN_<project>_v#.pdf
  8. Fab Filesfabrication / FAB_<project>_<material>_v#.dxf
Save dialogs open in these folders of the project# is the next number there

The Model and the Page

The Buttons

Alexandria Setup

Click
Adds the Alexandria Tools tab, the DM display modes, the Alexandria template in File > New and the Claude connectors. Click it again after every update.
Right
Set Panels arranges the right-hand panels to the standard.

Create Project

Click
Asks for a name and a folder, copies the project template there and saves a copy of the model in it. You carry on in the copy; the original stays. Never writes over an existing folder.

Populate Model

Click
Adds the standard layers, annotation styles, render backdrop and world light, and sets an empty model to inches. A second click only resets annotation styles you edited.

Set Material

Click
Pick a parent layer. Each sublayer gets a plaster material in its layer color, MAT_1, MAT_2…, replacing any it or its objects had. DESIGN::ILLUMS is left alone. Recolor a layer and click again to update.

Set Light

Click
Select surfaces, solids or meshes and choose a type. A type's objects share one V-Ray light. Shown in section, wall on the left.
Front Lit ChannelIntensity 4 · white
Reverse Lit ChannelIntensity 4 · white
Push Through BodyIntensity 2 · white · a solid
Push Through FaceIntensity 0.5 · charcoal

Apply Day Settings · Apply Night Settings

Click
Sets V-Ray to the day or night look, at 4K. Layers stay as you leave them: hide the wall to put the sign on the sky.
Right
Render Day and Save or Render Night and Save asks Save with sky (a JPEG with it, a transparent PNG without) and where to save, then renders the active view to one image.

Populate Detail

Click
Pick a detail, DTL-01 to DTL-13, and click where it goes. Fill in its blanks once, in the model.

Populate Block

Click
Pick a north arrow, section indicator, dot callout, graphic scale, person, car or tree and click where it goes. Symbols come in at paper size, the rest at true size. A callout takes the next number or letter.

Standard Dimension

Click
A dimension in the Alexandria style.
Right
Standard Leader draws a leader.

Layout Manager

Click
One window for the design package. Choose a part under Manage. Double click an entry for its main button.

Project DetailsEdit DetailsAdd Info PageProject, client and revisions, on the PROJECT INFO page.
DrawingsAdd DrawingEdit DrawingDelete DrawingPlace on PageRemove from PageA saved selection, placed as a Top view. Largest That Fits picks the scale.
Details · BlocksPlace on PageRemove from PageFrom the libraries.
CMFAdd ItemEdit ItemRemove ItemAdd CMF PagePaint, vinyl, materials and electrical, each with a code (P1, V1, M1, E1) and a swatch.
ImagesAdd ImageRemove ImageRender fills the page with a render over a day or night sky, which covers drawings there. Site Plan or Other: click two corners.
ExportExport PDFExport FactsEvery page, and the project facts beside it as FACTS_<project>_v#.html.

Fabrication Manager

Click
The fab team's cut linework, copied flat out of the model at 1:1. Never on a layout.
Add ItemName, material and line type, then select curves, text or hatches.
Add LineworkMore lines for the item in another line type.
Update ItemCopies it again after a design change. Edits to the old copies are lost.
Export DXFA file per material, in the model's units (inches), without the names.
Set LocationEdit ItemRemove Item

Save as Rhino 7 · Save as Rhino 8

Click
Writes <name>_r7.3dm or <name>_r8.3dm next to the model, over any earlier copy. You keep working in the original.

Layers

DESIGN::<part>The sign's parts.
DESIGN::ILLUMS::<type>Set Light's lit faces.
DETAILS::2DDetail linework: CUT, VISIBLE, FILL-…
DETAILS::2D::SIGN-LOCATIONThe red box that locates a sign on a plan or elevation.
DETAILS::ANNOTATIONSDIMENSIONS from Standard Dimension, CALLOUTS from Standard Leader.
FAB::<line type>Fab linework. FAB::LABELS holds the names.
RENDER::…Wall, ground, scale figure and world light.
LAYOUT::…The pages' parts. VARIABLE is the red per-project text: set it to gray when the package is final.
