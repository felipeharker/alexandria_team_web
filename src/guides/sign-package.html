Make a Package

  1. Fill In the DetailsProject, client and logo. Red text is still the template's.
  2. Add Pages and DrawingsAdd Drawing or Image, or drop files on the page.
  3. Give It a Real SizeClick a red dimension and type its real length. The rest fill in.
  4. Dimension and Call OutTwo points for a dimension; a point and a place for a callout.
  5. List the CMFPaint, vinyl, materials and electrical, each with a code and a swatch.
  6. Export PDFThen Save Package File, and keep both with the project.

A Drawing's Real Size

One real dimension is enough.

  1. Add the drawing. Its overall dimensions read X'-X" in red.
  2. Type one real length. Click a dimension you know, type it under Real Length, such as 21'-9", and press Enter.
  3. The rest fill in. Every dimension on that drawing follows.

Changing a Drawing's Parts

Change a drawing's colors and lines here, as in CorelDRAW.

  1. Open the drawing. Click it twice, or press Edit Its Parts.
  2. Select parts. Click, Shift-click or drag a box. Select Same Fill takes a whole color.
  3. Change them. Fill, Line, Line Weight and Opacity.
  4. Move, restack, delete. Drag or use the arrow keys, Bring to Front, Send to Back, or Delete.
  5. Dimension them. Add Their Dimensions draws the selection's width and height.
  6. Press Esc when you're done.
  • Your file isn't touched. Put It Back as Its File Has It clears every change.
  • It has to be all shapes. Save live text as outlines first. Trace a picture in the Vectorizer.

Good to Know

  • Red means not yet. Red text and red dimensions don't print. Export lists them first.
  • Click on the drawing's own points. A pink square shows the snap.
  • Click twice to edit a dimension's length, a callout's words or a drawing's parts.
  • Two ways to measure. Level or Plumb for an overall width or height, Parallel for a sloped edge. Shift swaps them.
  • Shortcuts. Ctrl+Z undoes, Ctrl+D duplicates, Ctrl+A selects all, Space and drag pans, Alt moves freely.
  • CMF codes in a callout. With a callout selected, CMF Code adds a code such as P1.
  • The same scope on every page. Set it once and press Use on Every Page.
  • Futura on the title page. Under Export, press Use Futura from This Computer (Chrome or Edge).
  • It saves in this browser. For another computer, Save Package File and open it there.
  • Not for cutting. The fab team cuts from the Fabrication Manager's files.
