Open the Material Estimator
  1. Project Name

    Names the sheet and its CSV. It starts as Untitled Project.

  2. Add Material

    A new row, set to the last row's pricing unit.

  3. Import CSV · Export CSV

    Bring a sheet in as a CSV, or take it out.

    • Importing onto a sheet with rows asks: Add to Sheet or Replace Sheet. A CSV dropped on the page imports too.
    • The sheet is saved in this browser only. Export a CSV to keep or share it.
  4. ⋯ Menu

    Download CSV Template, Load Example Sheet, Print / Save as PDF and Clear Sheet…

    • Clear Sheet… asks first.
  5. Material · Category

    Type a name to pick from the Material Library, which is empty for now.

    • A pick fills Category, Pricing Unit, Unit Price and Notes.
    • Enter moves to the same column in the next row. On the last row it starts a new one with the same unit and category.
    • Shift Enter moves up a row.
  6. Pricing Unit · Unit Price · Quantity

    Line Total is Unit Price times Quantity.

    • LF linear foot, SF square foot, SY square yard, CF cubic foot, CY cubic yard, EA each, LB pound, TON ton, GAL gallon, LS lump sum.
  7. Remove

    Deletes the row. An Undo button appears.

  8. Project Total

    The sheet's total, then split by pricing unit and by category.

    • By Category appears once a row has a category.

Price a Project

  1. Name the project
  2. Add a row per material
  3. Set each row's unit, price and quantity
  4. Check the totals
  5. Export the CSV to keep or share
