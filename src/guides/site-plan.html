Open the Site Plan
  1. Address

    Type a street, city and state, then press Search.

    • The first match is placed and zoomed to. Up to 5 matches list below: pick another to correct it.
    • Nothing found? Add the city and state, or click the map.
  2. Signs

    One row per sign, with its address and coordinates.

    • A search or a map click moves the selected sign. Add Sign makes the next one add another; Esc cancels.
    • Click a row to select it. × removes it.
    • New signs start with the last label, color and radius used.
  3. Map

    Click to place or move the sign. Scroll to zoom, drag to pan.

    • Buildings show from zoom 13, street names from 14. Zoom in to pick one.
    • The map never rotates: north is always up.
    • Click another sign's center or label to select it.
  4. Label

    Text inside the selected sign's circle, up to 40 characters.

    • Capitals only. It starts as SIGN LOCATION: clear it for none.
    • A long label shrinks to fit the circle.
  5. Circle Color

    Colors the selected sign's circle and label.

    • Pick a color, or type a hex code like #FF0000.
    • Reset to Red shows once it isn't red.
  6. Circle Radius

    The selected circle's size, in feet. It starts at 100.

    • The slider runs 10 to 1000. Type 5 to 5000 in the box.
  7. Highlight Buildings

    Click buildings to darken them. Click one again to undo.

    • The button reads Done while on: press it or Esc to finish. Clear removes them all.
  8. Street Names · Shadows · North Arrow · Scale Bar

    What the plan shows besides the map.

    • North Arrow and Scale Bar start on, bottom left. Street Names and Shadows start off.
    • The scale bar reads in feet, then in miles past one.
  9. Project Name

    Names the export. It starts as Untitled Project.

    • Everything autosaves in this browser, the map view too. The status beside the links says so.
  10. Export PNG

    Downloads the map exactly as framed on screen.

    • One file, Project Name Site Plan.png, 4,800 px wide. It lands in your browser's downloads.
    • Zoom buttons are left out. The OpenStreetMap credit is added bottom right.

Make a Site Plan

  1. Search the address, or click the map where the sign goes
  2. Add Sign for each extra location
  3. Set the label, color and radius
  4. Darken the client's building
  5. Choose street names, shadows, arrow and scale
  6. Zoom and pan to frame it, name the project, export
