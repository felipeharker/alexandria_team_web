The office's stock materials with sizes and prices, ready to add to an Estimator sheet. It is empty for now.

Open the Material Library
  1. Search Material, Finish or Supplier

    Type to narrow the tables.

    • It also matches Category, Thickness, Size and Notes.
  2. All · Categories

    Show everything, or only one category.

    • The count beside them reads like 3 of 3 Materials.
  3. A Row

    One material, grouped under its category.

  4. Price

    Per pricing unit, like $165.00 / EA. A dash means no price.

    • A guide only: check with the supplier before a quote.
  5. Add to Estimator →

    Adds a priced line to the Estimator's sheet and opens Quantity.

    • The name becomes Material, Thickness, Finish.
    • Size, Supplier and Notes go to the line's Notes.
  6. CSV Template

    A blank file for adding materials to the library.

    • Its columns are on the Material Library template page.

Add a Material to a Sheet

  1. Search, or pick a category
  2. Check the size and price
  3. Add it, then enter the quantity
