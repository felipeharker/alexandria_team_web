Open the Color Matcher
  1. Project Name

    Names the list and its exported CSV file.

  2. Add Color · Import CSV

    Add a color by hand, or load a list from a CSV.

    • On a list that already has colors, Import asks Add to List or Replace List. Replace also takes the project name from the file.
    • Or drop a CSV anywhere on the page.
    • Find Matches in the Color Library adds its color here.
  3. Export CSV

    Saves the list and each color's best matches as a CSV.

    • Named after the project. The columns are listed below.
  4. ⋯

    Four more actions.

    Download CSV TemplateA sample list to fill in
    Load Example ColorsThree colors, in place of the list
    Print / Save as PDFPrints the list with its matches
    Clear List…Removes every color, after asking
  5. Swatch

    Click it to pick a color with the browser's color picker.

  6. Name · Hex

    Type a hex code and the matches follow.

    • 3 or 6 digits, with or without #. A red border means it isn't a valid hex yet.
    • Lab is the color as the match reads it.
  7. Remove Color

    Removes the color. Undo stays on screen for a few seconds.

  8. Sherwin-Williams · Pantone Solid Coated · 3M Scotchcal 3630

    Each library's three nearest colors, best first.

    • Percent is 100 less 2.5 for every ΔE. The word beside it is in the table below.
    • The small line is the hex and any note, such as a 3M color's Pantone code.
    • Screens are approximate: check a physical swatch before ordering.
  9. Formula on File

    Opens that color's Matthews Paint formula in the Color Library.

    • Only Sherwin-Williams and Pantone matches have one. A color with two formulas gets two tags.
  10. Saved in This Browser

    The list autosaves here, and nowhere else.

    • Export CSV to keep it or share it.
    • It reads Not Saved when the browser blocks storage.

Match a Color

  1. Add a color, or import a CSV list
  2. Type its hex code, or pick it by eye
  3. Read the percent and word in each column
  4. Open Formula on File where the office can mix it
  5. Export the CSV to keep the list

Reading a Match
