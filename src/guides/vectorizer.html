Open the Vectorizer
  1. Choose Image

    PNG, JPG, WebP or GIF. Nothing is uploaded.

    • Or drop the file anywhere, or paste it with Ctrl V.
    • Use the largest, cleanest file the client has.
  2. Colors

    The most colors to look for, 2 to 16.

    • Blends and near-duplicates are dropped, so the list can come out shorter.
    • A color missing from the list? Raise it.
  3. The Color List

    Every color found, largest share first.

    TickedKept, as its own shape
    UntickedMerged into the nearest color left
    OmitLeft empty: the checkerboard. Press again to bring it back.
  4. Keep a Color · Omit a Color

    Press one, then click that color in the image.

    • For a color the list missed. Esc cancels.
  5. Precision · Clean Geometry

    How closely the shapes follow the image.

    Lumpy curvesLower Precision
    Lost detailRaise Precision
    Clean GeometrySquares up edges and trues circles. Leave it off for hand-drawn shapes.
  6. Vector · Original · Outlines

    Three views of the same image.

    • Outlines shows the paths alone: check the curves there.
  7. Zoom

    Scroll to zoom, drag to pan, Fit to see it all.

  8. File Name

    Names the download. It starts as the image's name.

  9. Download SVG · Copy SVG

    The file, or its code on the clipboard.

    • One shape per kept color. Neighbours share a border, with no gaps or overlaps.
    • Sized in the image's pixels: scale it where you place it.
    • Letters come out as shapes. Retype them if they'll be edited.

Trace a Logo

  1. Open the image
  2. Omit the background, usually white
  3. Untick the extra colors
  4. Check the curves in Outlines, then set Precision
  5. Download the SVG, then scale it in Rhino or CorelDRAW
