A part label in, single lines out: an SVG or DXF at real size for a laser or router to follow once.

Open Etch Text
  1. Text

    Each line of text is a line of etching.

    • Lower case is drawn as capitals.
    • The font has 61 characters: 0-9, A-Z and common punctuation. A missing one is named in red and left out, its space kept.
    • The text, sizes and alignment are remembered in this browser.
  2. Size

    Letter Height and Letter Spacing in inches, Line Spacing in letter heights.

    • Starts at 0.5 in, 0 in and 1.6 ×. Reset the Size appears once one changes.
    • Height is the capitals'. A negative Letter Spacing pulls letters together.
    • Line Spacing is baseline to baseline.
  3. Align

    Where shorter lines sit against the longest.

  4. Dashed: baseline · top of the capitals

    The lines as they will be etched, with two guides per line.

    • The guides are not in the files.
  5. Download SVG · Download DXF · Copy SVG · SVG as Text

    Four ways out, all at real size in inches.

    • Files are named Etch and the first line, such as Etch P1-1.svg.
    • The line under them gives strokes, size and inches of etching.
    • Greyed out until there is text to etch.

Make a Label

  1. Type the label
  2. Set the letter height, and the spacing for more than one line
  3. Check the lines against the guides
