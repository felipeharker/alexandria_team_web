Good to Know

  • Never fill it. Give the lines a hairline outline and no fill.
  • No margin. The file is exactly the letters' size.
  • Not in the font? A missing character is named in red and left out.
  • In Rhino. A script draws labels straight into a model. See Alexandria Etch Font.
  • It saves in this browser.
